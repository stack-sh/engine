# Stack Engine 0.8.0

## Clearer diagrams by default

- Compose connected nodes and nested groups in graph-aware ranks while preserving explicit direction, same-rank constraints, and authored cross-axis order.
- Reserve room for measured labels before routing. Keep labels beside their own routes and keep lines away from text, node borders, and parallel group frames.
- Bundle Theme 0.6.0: database nodes use a rounded card and their existing database icon.
- Serialize diagram-space SVG coordinates, fonts, and strokes in exact CSS pixel decimals. This avoids browser clamping and rendering artifacts from oversized millipixel user coordinates.

The native Rust engine and browser WASM adapter share these changes. Public operation and language-intelligence contracts are unchanged; generated SVG geometry and serialization intentionally differ from 0.7.0. Consumers comparing exact SVG bytes should update reviewed references. Existing custom catalogs with wider connector strokes retain labelled rendering support.

## Verification and limits

The release uses approved scene/SVG snapshots, a seven-diagram quality corpus, sixty fixed labelled-DAG regressions, native/WASM parity, and existing performance budgets. Independent gates measure logical text envelopes and painted frame clearance; they also reject missing content, unsupported geometry, hidden paint, and altered paint order. Geometry checks supplement rather than replace visual review; they do not prove beauty or measure exact rasterized glyphs and arrowheads.

The engine remains pure Rust with no runtime filesystem, network, clock, DOM, or host-font access. No custom-palette configuration format or theme-authoring service is introduced in this release.
